## Laptop script from Moncef Belyamani

_Laptop is a script that will set up a complete Ruby web development environment on your Mac, including Node, Postgres, Rails, and Jekyll. You also have the option to skip those web dev tools and only install the minimum required to use Ruby._

Often I had problems with my Jekyll installation and a very hard time to solve several problems. After checking many sites and forums I found the Laptop script from Moncef Belyamani.

This script makes not only the installing of Homebrew, Ruby, Rails and Jekyll on a Mac easier, it also keeps everything up to date.

[Website von Moncef Belyamani](https://www.moncefbelyamani.com); [Laptop script on github](https://github.com/monfresh/laptop)
